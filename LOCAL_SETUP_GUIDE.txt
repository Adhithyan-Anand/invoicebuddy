# Invoice Management System - Local Setup Guide

## Prerequisites

### For macOS:
1. Install Node.js (version 18 or higher)
   - Download from https://nodejs.org/
   - Or use Homebrew: `brew install node`

2. Install PostgreSQL
   - Download from https://www.postgresql.org/download/macosx/
   - Or use Homebrew: `brew install postgresql`
   - Start PostgreSQL: `brew services start postgresql`

3. Install Git (if not already installed)
   - Download from https://git-scm.com/
   - Or use Homebrew: `brew install git`

### For Windows:
1. Install Node.js (version 18 or higher)
   - Download from https://nodejs.org/
   - Make sure to check "Add to PATH" during installation

2. Install PostgreSQL
   - Download from https://www.postgresql.org/download/windows/
   - Remember the password you set for the postgres user
   - Add PostgreSQL bin directory to your PATH

3. Install Git
   - Download from https://git-scm.com/download/win

## Setup Instructions

### 1. Clone or Download the Project
```bash
# If using Git:
git clone <your-repository-url>
cd invoice-management-system

# Or extract the downloaded ZIP file and navigate to the project directory
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Database Setup

#### Create Database:
```sql
-- Connect to PostgreSQL as superuser
psql -U postgres

-- Create database and user
CREATE DATABASE invoice_db;
CREATE USER invoice_user WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE invoice_db TO invoice_user;

-- Exit psql
\q
```

#### Set Environment Variables:
Create a `.env` file in the project root:

**For macOS/Linux:**
```env
DATABASE_URL=postgresql://invoice_user:your_secure_password@localhost:5432/invoice_db
PGHOST=localhost
PGPORT=5432
PGUSER=invoice_user
PGPASSWORD=your_secure_password
PGDATABASE=invoice_db
SESSION_SECRET=your_very_long_random_secret_key_here_min_32_chars
NODE_ENV=development
```

**For Windows:**
```env
DATABASE_URL=postgresql://invoice_user:your_secure_password@localhost:5432/invoice_db
PGHOST=localhost
PGPORT=5432
PGUSER=invoice_user
PGPASSWORD=your_secure_password
PGDATABASE=invoice_db
SESSION_SECRET=your_very_long_random_secret_key_here_min_32_chars
NODE_ENV=development
```

### 4. Database Migration
```bash
# Push database schema
npm run db:push
```

### 5. Start the Application
```bash
# Start in development mode
npm run dev
```

The application will be available at: http://localhost:5000

## Troubleshooting

### Common Issues:

1. **Database Connection Error**:
   - Ensure PostgreSQL is running
   - Check your DATABASE_URL in .env
   - Verify database credentials

2. **Port 5000 Already in Use**:
   - Kill the process using port 5000
   - Or change the port in server/index.ts

3. **Session Secret Error**:
   - Ensure SESSION_SECRET is at least 32 characters long
   - Generate a secure random string

4. **Dependencies Installation Failed**:
   - Clear npm cache: `npm cache clean --force`
   - Delete node_modules and package-lock.json
   - Run `npm install` again

## Security Notes

- Always use strong passwords for database users
- Keep your SESSION_SECRET secure and never commit it to version control
- Use environment variables for all sensitive configuration
- Consider using SSL for database connections in production

## Production Deployment

For production deployment:
1. Set NODE_ENV=production in your .env file
2. Use a secure database host (not localhost)
3. Use SSL for database connections
4. Set secure session configuration
5. Use a reverse proxy like nginx
6. Set up proper firewall rules

## Support

If you encounter issues:
1. Check the console for error messages
2. Verify all environment variables are set correctly
3. Ensure database is running and accessible
4. Check network connectivity if using remote database
